# Smart Login System
This is a basic Python project that simulates a simple login system.

The system:
- Checks username and password
- Allows only 3 login attempts
- Blocks the account after 3 incorrect attempts

## How It Works
1. The program stores a predefined username and password.
2. The user gets a maximum of 3 attempts to enter correct credentials.
3. If the credentials match, login is successful.
4. If the user fails 3 times, the account is blocked.

Enter the Password : admin123
